# 拾った異常の切り分け

モンキーテストは**ランダムに触る**ので、異常の一覧には仕様どおりの挙動と開発環境由来の
ノイズが混ざる。そのまま報告すると「バグ 12 件」のような嘘になる。
`findings` の 1 件ずつを次の表に当てて、`実バグ` / `ノイズ` / `判断保留` に分ける。

## ノイズとして落とすもの

| 見え方 | 正体 | 判断 |
|---|---|---|
| `console` warn に `[MSW] Warning: intercepted a request without a matching request handler` | ハンドラ未定義の API。未実装 API を素通しする設計どおり（CLAUDE.md「API モック」） | ノイズ。ただし**その画面が使う API なら「ハンドラ未追加」として報告する** |
| `network` の `http://frontend:5173/@vite/client` 系・WebSocket の失敗 | Vite の HMR。dev サーバ固有 | ノイズ |
| `network` の `404 GET /favicon.ico` | 開発環境にアイコンが無いだけ | ノイズ |
| `console` error に `Failed to load resource` だけが出て、対応する 5xx が無い | 上 2 つの言い換え | ノイズ |
| `render` warn の「横スクロールが発生」が**操作前から出ている**（step 1 で出る） | 画面の既定レイアウト。モンキーテストが壊したわけではない | ノイズ（レイアウト課題として別途 1 行だけ触れる） |
| `dialog`（severity `info`） | 確認ダイアログをランナーが「いいえ」で閉じた記録 | ノイズ。**件数として数えない** |
| `unexpected-navigation` で遷移先が**その画面の詳細・編集画面** | 画面内のリンクを踏んだだけ。画面をまたぐ操作は対象外なので戻している | ノイズ |

## 実バグとして報告するもの

| 見え方 | 意味 |
|---|---|
| `pageerror`（未処理の例外・Promise 拒否） | **最優先。** ランダム入力で確実に落ちる経路がある |
| `render` error の「#app が空（白画面）」 | 描画が死んでいる。例外と対で出ることが多い |
| `console` error の Vue 警告（`[Vue warn]`） | props の型・必須漏れ・重複 key など。dev ビルドでしか出ないが**原因はコード側** |
| `network` の 5xx が**自前の MSW ハンドラに対して**出た | ハンドラかフィクスチャの不整合 |
| `unexpected-navigation` で `/`（注文一覧）や「ページが見つかりません」へ飛んだ | 画面内の操作で画面が抜けている。ルーティングか遷移処理の誤り |
| 同じ操作を 2 回撒くと壊れる（`actions` に同じ要素が連続で出ている箇所） | 二重送信・多重オープンの防御漏れ |

## 「仕様どおり」として落とす前に確認すること

ランダムな入力（`monkey/random.js` の `randomText`）は不正値を意図して混ぜている。
**入力を弾くこと自体はバグではない。** ただし次は実バグ側に寄せる。

- 不正値でエラー表示が出ず、**何も起きない**（利用者に伝わらない）
- 不正値で**画面全体がエラー状態**になり、以降どの操作も受け付けない
- 4 状態（ローディング / エラー / 空 / データあり）のどれでもない中間状態で止まる
  （CLAUDE.md「レイヤ規約」の最後の項目）

## 判断保留に置くもの

- 同じ seed で再実行しても**再現しなかった**もの（タイミング依存の疑い）
- 仕様が決まっていない画面の挙動（`docs/api/openapi.json` にギャップが残る範囲）
- `failed(...)` として `actions` に残っている操作
  （要素が消えた・アニメーション中などランナー側の取りこぼし。異常ではないが、
  同じ箇所で大量に出るなら要素の拾い方の問題として書く）
