### #45 `POST /masters/customers/validate` が 500 を返す（不具合）

**背景**: 顧客マスタの「新規追加」は登録前に必ず事前検証を呼ぶので、**実 API では顧客を 1 件も登録できません**。

2026-10-05 の実 API E2E（`CUR-02`）で、次の本文を `POST /api/masters/customers/validate` に送ると
`500 {"detail":"内部サーバーエラーが発生しました"}` が返りました（2 回とも同じ。`生年月日: "19800101"` を足しても変わらず）。

```json
{
  "口座番号": 2035000,
  "部店コード": "100",
  "扱者コード": "100",
  "顧客名": "E2E実API確認 顧客",
  "顧客名カナ": "ﾃｽﾄ",
  "法人区分": "0",
  "コンプラランク": "A",
  "総預り資産": 0
}
```

このほか `CustomerValidateRequest` で required の項目は画面の既定値で埋めています。部店 100・扱者 100 は顧客一覧に実在する組です。

**依頼内容**

| # | 内容 |

| ① | 500 の原因（サーバログの例外）。本文の項目に起因するなら、どの項目か |
