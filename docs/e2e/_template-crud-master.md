# 〈画面名〉（雛形: CRUD マスタ）

- 略号: `XX`
- 画面: `src/views/〈Name〉ListView.vue`
- テスト: `e2e/〈kebab-name〉.spec.js`

> **これは雛形。** コピーして `XX` / `〈画面名〉` / `/masters/xxx` / 件数 / 列名 / 入力項目を差し替え、固有の行を足す。
> `_` 始まりのファイルは `check:scenarios` が読まない。原型は銘柄マスタ（`SM-01〜34`）。
> 一覧・検索（01〜10）は `_template-search-list.md` と同じ骨格。

`/masters/xxx` の受け入れ条件。一覧・検索（XX-01〜10）に加えて、ヘッダの「新規追加」からの登録（XX-13〜20）・
行ごとの編集（XX-21〜27）・行ごとの削除（XX-30〜34）を含む。

登録・編集は「サーバの事前検証 → 登録 / 更新」の 2 段で、エラーの出し先が 3 系統に分かれる
（必須未入力は項目の直下 / 事前検証の不合格は箇条書き / 通信・サーバ障害は専用の表示）。
更新は取得時の更新日時を送り返す楽観的ロック付きで、409 は通信・サーバ障害と同じ枠に出す。

**業務キー（〈キー項目〉）は編集で変更できない**（`*UpdateRequest` にその項目が無い。読み取り専用にする）。
パスキーが ID のマスタ（CA / 残高調整 / 手数料パターン / 手数料優遇）ではこの制約は無いので、その記述を消す。
