フロントとバックエンドの噛み合わせだけ**を見る。

## なぜ分けるか

`XX` はフィクスチャの中身（件数・先頭行の値）を期待値にしている。実 API に当てるとデータが違うので全滅し、
`mockApi()`（`window.__mswOverrides`）は MSW を切ると効かないため、エラー応答や 0 件の再現も成立しない。
そこで**データの中身に依存しない不変条件**だけを書く。件数・値は実行時に画面か API から読み取って比べる。

## 実行方法

既定では**動かない**（`E2E_REAL_API` が無ければ丸ごとスキップ）。前提は MSW off とバックエンドの起動。

```powershell
docker compose run --rm -e E2E_REAL_API=1 e2e npx playwright test 〈kebab-name〉.real-api
```

MSW が有効なままだと実 API を見ていないので、各シナリオの冒頭で検出して失敗させる。

## 実データを書き換える

XXR-02 以降は**実 DB に登録・更新・削除を行う**。ローカルの開発 DB 前提。
〈どちらか 1 つを残す〉

- **業務キーのあるマスタ:** 業務キーは 2035 年の日付 / `E2E-` で始まる値に寄せ、**まだ一度も使われていない値**を実行時に選ぶ
  （論理削除のマスタで使い回すと「再有効化」の経路に入る）。終了時に論理削除するので有効な行は残らない
- **自然キーの無いマスタ:** 備考などの自由入力欄に目印（`marker()` の接頭辞）を入れ、開始時と終了時に目印付きの有効な行を消す

1 回の実行につき DB に残るもの: 〈取消済みの行が N 件 / 何も残らない〉
