# 〈画面名〉（雛形: 検索一覧）

- 略号: `XX`
- 画面: `src/views/〈Name〉ListView.vue`
- テスト: `e2e/〈kebab-name〉.spec.js`

> **これは雛形。** コピーして `XX` / `〈画面名〉` / `/xxx` / 件数 / 列名を差し替え、固有の行を足す。
> `_` 始まりのファイルは `check:scenarios` が読まない。原型は顧客マスタ（`CU-01〜15`）と操作ログ。

`/xxx` の受け入れ条件。ページ位置と検索条件は URL クエリ（`offset` / `〈query1〉` / `〈query2〉`）を正としているため、
**実ブラウザでの URL と画面の同期**をここで守る。

既定モックは有効な行 56 件（1 ページ 50 件）で、並びは〈並び順〉。先頭行は〈先頭行の識別子〉。
モックはこのほかに取消済みの行を 1 件持つが、既定の一覧には出ない。

ローディングの過渡状態、手で URL に書いた未知のコード、表示件数の倍数でない `offset` は、
画面の導線からは起こらない（または実ブラウザでは安定して観測できない）ので単体テスト側の担保に譲り、ここには書かない。
