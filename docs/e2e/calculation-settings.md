# 仮計算マスタ

- 略号: `PC`
- 画面: `src/views/CalculationSettingsMasterView.vue`（`/masters/provisional-calculation`）
- テスト: `e2e/calculation-settings.spec.js`
- 単体側のシナリオ: [docs/unit/views-calculation-settings-master-view.md](../unit/views-calculation-settings-master-view.md)

仮計算にだけ使う 4 つの値 —— 取引所税 / スプレッド / 現地手数料率 / NISA仮計算用為替上乗せ率 ——
を表示し、変更する画面（「現在の設定」と「設定変更」の 2 カード。スライス基準マスタと同じ構成）。
ここで守るのは「現在値が読めること」「保存した値が現在値に反映されること」
「読み込みと保存の失敗・入力の不備が利用者に伝わること」の 3 点。
値の整形（桁数・単位換算の端数）、入力欄の初期化、数値でない値や桁あふれの検査、ローディング表示は
単体側（`PCV`）に委ねる。

既定モック（`src/mocks/fixtures/calculationSettings.js`）は 取引所税 `0.002000%`（比率 0.00002）/
スプレッド `0.5000 円/USD` / 現地手数料率 `0.100000%`（10 bp）/ NISA `5.0000%`、
最終更新 2026-09-29 09:00・更新者 `BATCH`。入力欄は % で扱い、保存時に API の単位
（比率 / bp）へ換算する。

MSW のハンドラ（`src/mocks/handlers/calculationSettings.js`）は実 API と同じ形で拒否する
（範囲外は 422 の `HTTPValidationError`、楽観的ロックの競合は 409 の `ErrorResponse`）。
**拒否の文言はサーバ側の資産なので、ここでは固定しない**。モックの可変状態はページ単位で、
保存しても他のテストには持ち越さない。

更新権限の出し分けはルートの `requiredPermission: 'master'` で行い、画面内に「閲覧のみ」は置かない
（為替マスタと同じ。権限の検証は `docs/e2e/access-control.md` 側）。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| PC-01 | 既定モック | 仮計算マスタを開く | `0.002000%` / `0.5000 円/USD` / `0.100000%` / `5.0000%` と、最終更新の日時・更新者 `BATCH` が表示される | 実装済 |
| PC-02 | 設定の取得が 500 を返す | 仮計算マスタを開く | エラーメッセージ（サーバーでエラーが発生しました。）と「再試行」ボタンが表示され、設定変更フォームは表示されない | 実装済 |
| PC-03 | 設定の取得が本文なし（null）を返す | 仮計算マスタを開く | 「仮計算マスタが設定されていません。」が表示され、設定変更フォームは表示されない | 実装済 |
| PC-04 | 既定モック | 取引所税を `0.003`、現地手数料率を `0.15` にして「保存」を押す | 「仮計算マスタを変更しました。」が表示され、現在値が `0.003000%` / `0.150000%` に変わる | 実装済 |
| PC-05 | 既定モック | 何も変えずに「保存」を押す | 「変更はありません。」が表示され、現在値は変わらない | 実装済 |
| PC-06 | 既定モック | NISA仮計算用為替上乗せ率を `101` にして「保存」を押す | 保存できない理由が表示され、成功メッセージは出ず、現在値は `5.0000%` のまま変わらない | 実装済 |
| PC-07 | 保存が 409（他の担当者が先に更新）を返す | 取引所税を `0.003` にして「保存」を押す | 先に更新された旨が表示され、成功メッセージは出ず、現在値は `0.002000%` のまま変わらない | 実装済 |
| PC-08 | 既定モック | スプレッドを空欄にして「保存」を押す | 「スプレッドを入力してください。」が表示され、保存は行われず（成功メッセージも保存できない理由も出ない）、現在値は `0.5000 円/USD` のまま | 実装済 |
| PC-09 | 既定モック、注文一覧を開いている | サイドメニューの「仮計算マスタ」を押す | URL が `/masters/provisional-calculation` になり、現在の設定が表示される（「ページが見つかりません」にならない） | 実装済 |
