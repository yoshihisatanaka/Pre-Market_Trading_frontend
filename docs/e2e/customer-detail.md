# 顧客詳細

- 略号: `CDT`
- 画面: `src/views/CustomerDetailView.vue`（枠）/ `src/views/CustomerSummaryView.vue`（外株預りタブ）/
  `src/views/CustomerOrdersView.vue`（注文照会タブ）/ `src/views/CustomerCalculationView.vue`（仮計算タブ）
- テスト: `e2e/customer-detail.spec.js`

**当てる先は MSW のモック。** 期待値にフィクスチャの中身（顧客名・銘柄・注文 ID・金額）を使うので、実 API に当てると通らない。

`/customers/:customerId/summary`・`/customers/:customerId/orders`・`/customers/:customerId/calculations` の受け入れ条件。
顧客検索の顧客名から入り、枠（顧客カードとタブ）が顧客を 1 回読み、タブの中身を子ルートが描く。
`/customers/:customerId` だけを開くと外株預りへ回る。ここで守るのは次の 4 つ。

- **4 状態**を 3 か所で: 顧客（読み込み中 / 見つからない（404）/ エラー / データあり）、外株預りの一覧、注文照会の一覧
- **タブと URL の同期**（タブを押すと URL が変わり、選択中のタブが変わる。注文照会タブの絞り込みは URL クエリ `symbol` / `status` に載る）
- **新規注文への引き継ぎ**（タブの「注文入力」・「＋ 新規注文」・預りの「買い」「売り」）。URL クエリで渡し、
  **新規注文の画面の入力欄に値が入るところまで**を実ブラウザで通す。仮計算タブへの引き継ぎ（預りの「仮計算」）も同じ
- 発注権限（`GET /auth/me` の `権限.order`）での出し分け。権限なしは `/auth/me` を `noOperationOperator` に差し替えて見る。
  「仮計算」は発注ではないので権限なしでも出る

**仮計算タブは `POST /calculations` につながっている**（既定モックは `src/mocks/handlers/calculations.js`、
計算は `src/mocks/fixtures/calculations.js`）。ここではタブ・導線・引き継ぎに加えて、結果のカードの 4 状態
（未実行 / 計算中 / 計算できなかった / 結果あり）と、代表の結果 2 通り（特定の売り・成長投資枠の買い）、
入力不備で API を呼ばないこと、400 の理由・サーバの注意（warnings）・通信障害の出しかたを見る。
金額の計算式・丸め、各入力欄の桁数・形式の検査、結果の行の見出しの出し分け（手入力 / 自動）は
単体テスト側（`src/utils/calculationForm.js` / `src/stores/calculation.js` / `src/views/CustomerCalculationView.vue` の spec）に譲る。
結果の金額は既定モックで計算した値（浮動小数の末尾の桁は保証されないので、フィクスチャから組み立て直さない）。

既定モックの顧客は `src/mocks/fixtures/customers.js`。顧客 ID 1 は部店 123・口座 1230001・山田 太郎
（75 歳・コンプラ A「要注意」・取引制限なし）、ID 5 は全取引停止、ID 9 は法人（年齢なし）、ID 3 は保有も注文も無い顧客。
ID 9999 は居ない（404）。預りは `src/mocks/fixtures/holdings.js` で、ID 1 は 4 銘柄
（AAPL 評価益 / MSFT 評価損・売却不可 / NVDA 成長投資枠 / TSLA 非特定・損益 0・CA 発生中）。
顧客カードの「米国株評価額」「評価損益」は預りの合計。注文は `src/mocks/fixtures/orderInquiry.js` で、
口座 1230001 は 3 件（`#38` とその訂正 `#42`、`#41`）、画面の行は元注文ごとにまとめた 2 行（`#38` / `#41`）。

預りの特定預り区分 → 注文の預り区分の読み替え（特定 → 特定 / 非特定 → 一般 / 成長投資枠 → 成長投資枠、
成長投資枠の買いは引き継がない）の分岐、手で書き換えた URL クエリの読み捨て、顧客の切り替え時の古い応答の破棄、
評価額の上限超え（200 件超で「—」）は単体テスト側（`src/utils/orderEntryQuery.js` / `src/stores/customerDetail.js` /
`src/views/CustomerSummaryView.vue` の spec）の担保に譲り、ここには代表の 3 通り（AAPL の買い・TSLA の売り・NVDA の買い）だけを書く。
