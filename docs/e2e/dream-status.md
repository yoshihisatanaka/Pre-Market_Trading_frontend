# Dream登録状況

- 略号: `DS`
- 画面: `src/views/DreamStatusListView.vue`
- テスト: `e2e/dream-status.spec.js`

**当てる先は MSW のモック。** 期待値にフィクスチャの中身（56 件・特定の注文 ID・エラー文言）を
使うので、実 API に当てると通らない。実 API との噛み合わせを見る版はまだ無い。

`/orders/dream-status` の受け入れ条件。ページ位置と検索条件は URL クエリ（`offset` / `branch_code` /
`account_number` / `symbol` / `dream_status` / `registered_from` / `registered_to` / `dream_ref`）を正としているため、
**実ブラウザでの URL と画面の同期**（DS-11 / DS-15 / DS-16）をここで守る。

既定モックは 56 件（1 ページ 50 件）で、並びは作成日時の新しい順。先頭 8 件が Dream状況 8 種
（登録失敗 / 登録済 / 未登録 / 取消失敗 / 登録中 / 登録対象外 / 取消中 / 取消済）を 1 件ずつ含み、
先頭行は注文ID `#56`（登録失敗・受付番号なし）。2 ページ目にも登録失敗が 1 件（`#3`）ある。
エラー（登録失敗・取消失敗）の行は `#56` / `#53` / `#3` の 3 件。

STS変更は**ダイアログを開くところまで**が対象。送信はまだ繋いでいないので、主ボタン「変更する」は
押せない（DS-08 / DS-09）。送信の導線が入ったら行を足す。

ローディングの過渡状態、口座番号に数字以外を入れたときの扱い、日付の書式、
「登録済」への変更で受付番号が既にある行（既定モックにその組み合わせの行が無い）、
遷移先の名前の組み立ては、画面の導線からは安定して観測できないか既定モックで再現できないので
単体テスト側の担保に譲り、ここには書かない。
