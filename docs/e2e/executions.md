# 約定照会

- 略号: `EX`
- 画面: `src/views/ExecutionListView.vue`
- テスト: `e2e/executions.spec.js`

`/executions` の受け入れ条件。ページ位置と検索条件は URL クエリ（`offset` / `branch_code` / `symbol` / `side` /
`status` / `start_date` / `end_date` / `route`）を正としているため、**実ブラウザでの URL と画面の同期**をここで守る。

既定モックは約定 56 件（1 ページ 50 件）で、並びは約定日時の降順。先頭行は約定ID `#56`。
内訳は 買 38 件 / 売 18 件、出来状況は 全部出来 44 件 / 一部出来 8 件 / 取消済（出来有）4 件、
銘柄 `AAPL` は 7 件、約定日 2026-09-28 は 8 件（`src/mocks/fixtures/executions.js` の生成規則から導く）。

いまは UI だけの段階で、CSV 出力と預託先のロールによる出し分けは繋いでいない。そちらの行は処理を入れるときに足す。

ローディングの過渡状態、手で URL に書いた未知のコード、表示件数の倍数でない `offset` は、
画面の導線からは起こらない（または実ブラウザでは安定して観測できない）ので単体テスト側の担保に譲り、ここには書かない。
