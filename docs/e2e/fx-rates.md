# 為替マスタ

- 略号: `FX`
- 画面: `src/views/FxRateMasterView.vue`（`/masters/fx`）
- テスト: `e2e/fx-rates.spec.js`

USD/JPY の現在レートを 1 件表示し、「レート更新」モーダルから今日（JST）のレートを保存する画面。
ここで守るのは「現在レートが読めること」「保存した値と今日の基準日が現在値に反映されること」
「今日の行があれば変更、無ければ登録に分かれること」「入力不備・事前検証・サーバ拒否の理由が
モーダルに出ること」の 4 点。レートの桁整形、入力欄の初期値、警告の承知フラグの持ち越しといった
画面内部の振る舞いは単体側に委ねる。

既定モック（`src/mocks/fixtures/fxRates.js`）は基準日がすべて過去で、最新の有効な行は
`2026-07-31` / `150.25`（取消済みの `2026-08-01` / `999.99` は出ない）。
既定では今日の行が無いので、保存は**登録（POST）**の経路を通る。
**変更（PUT）**の経路は、最新（latest）と詳細が「今日（JST）の基準日の行」を返すよう差し替えて再現する。
モックの可変状態はページ単位（読み込み直すとフィクスチャに戻る）なので、保存しても他のテストには持ち越さない。

事前検証（`/masters/fx/validate`）は一般的な範囲 50〜300 円から外れると警告を返す（保存は止めない）。
拒否の文言はサーバ側の資産なので、ここでは文言の一部だけを見る。

## 保存を伴う行（FX-05 / 06 / 08 / 09 / 10 / 13）が保留の理由

2026-09-29 時点で、レート欄に数値を入れて「更新」を押すと、画面が保存に進まない
（モーダルは開いたまま、エラーも出ない）。ページには
`TypeError: rateInput.value.trim is not a function` が出る。

`<input type="number">` の `v-model` は、Vue が入力値を Number に変換して返す。
`FxRateMasterView.vue` の `submitUpdate` は入力値を文字列とみなして `trim()` を呼ぶので、
数値を入れると必ず例外になる（空欄のときだけ `''` のまま届くので、FX-07 は通る）。

テストは書いてあり `test.fixme` で止めてある。テスト側だけで入力値を文字列に戻して流すと
6 本とも通ることを確かめ済み。製品側が直ったら `test.fixme` を `test` に戻し、状態を実装済にする。

| FX-02 | 既定モック、応答を遅らせる | 為替マスタを開く | 応答が返るまで読み込み中の表示が出て、返ったら現在レートに替わる | 実装済 |
| FX-03 | 最新レートの取得が 500 | 為替マスタを開く | エラーメッセージと「再試行」ボタンが表示され、現在レートは出ず、「レート更新」は押せない | 実装済 |
| FX-04 | 最新レートが 404（1 件も登録が無い） | 為替マスタを開く | 「USD/JPY の為替レートが登録されていません。」が表示され、「レート更新」は押せる | 実装済 |
| FX-05 | 既定モック（今日の行が無い） | 「レート更新」でレートを `151` にして「更新」を押す | モーダルが閉じ、「USD/JPY のレートを 151.00 円に更新しました。」が出て、現在レートが `151.00`・基準日が今日（JST）になる | 保留 |
| FX-06 | 最新と詳細が今日（JST）の基準日の行を返す、登録は 500 | 「レート更新」でレートを `151` にして「更新」を押す | 登録ではなく変更として受理され、成功メッセージが出て現在レートが `151.00` になる | 保留 |
| FX-07 | 既定モック | 「レート更新」でレート欄を空にして「更新」を押す | 「レートを入力してください。」が出てモーダルは開いたまま、現在レートは `150.25` のまま | 実装済 |

| FX-11 | 既定モック | 「レート更新」でレートを `151` にして「キャンセル」を押す | モーダルが閉じ、成功メッセージは出ず、現在レートは `150.25` のまま | 実装済 |
| FX-12 | 既定モック、注文一覧を開いている | サイドメニューの「為替マスタ」を押す | URL が `/masters/fx` になり、現在レートが表示される（「ページが見つかりません」にならない） | 実装済 |
| FX-13 | 最新レートが 404（1 件も登録が無い） | 「レート更新」を開き（レート欄は空）、`151` を入れて「更新」を押す | 成功メッセージが出て、未登録の表示が現在レート `151.00`・基準日が今日（JST）に替わる | 保留 |
