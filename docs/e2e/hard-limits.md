# ハードリミットマスタ

- 略号: `HL`
- 画面: `src/views/HardLimitMasterView.vue`
- テスト: `e2e/hard-limits.spec.js`
- 単体側のシナリオ: [docs/unit/views-hard-limit-master-view.md](../unit/views-hard-limit-master-view.md)

注文の自動分割（スライス）を決める 3 つの上限 —— 市場関与率 / 1注文あたり数量 / 1注文あたり金額 ——
を表示し、変更する画面。ここで守るのは「現在値が読めること」「保存した値が現在値に反映されること」
「読み込みと保存の失敗が利用者に伝わること」の 3 点。値の整形や入力欄の初期化といった画面内部の
振る舞いは単体側（`HLV`）に委ねる。

既定モックは 市場関与率 5.00% / 数量 10,000 株 / 金額 USD 1,000,000。
入力欄の市場関与率は % で扱う（比率 0.05 ↔ 入力 5）。

> **状態について**: `e2e/hard-limits.spec.js` は実装済みだが、Docker（frontend コンテナ）を
> 他セッションが使用中で実行できていないため、状態は全行 `未着手` のまま置いてある。
> Docker が空いたら `docker compose run --rm e2e npx playwright test hard-limits` を通し、
> 状態を `実装済` に更新すること。
