# 共通レイアウト（サイドメニュー / ヘッダ）

- 略号: `LAY`
- 画面: `src/components/layout/`（`AppLayout` / `AppSidebar` / `AppHeader`）
- テスト: `e2e/layout.spec.js`
- モック原本: `docs/mock/layout/masters-users.html`

全画面に出る共通部分の受け入れ条件。**個々の画面固有の要素（例: 注文一覧の「再読み込み」ボタン）は
その画面のシナリオ（[order-list.md](order-list.md)）で扱い、ここには書かない。**
メニューの遷移先はまだ大半が未実装のため、「ページが見つかりません」に落ちるのが正常。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| LAY-01 | 既定モック | `/` を開く | サイドバーに「米株発注システム」、見出し 顧客 / 注文 / マスタメンテ、リンク 14 件（顧客検索 … 残高補正）が表示される | 実装済 |
| LAY-02 | 既定モック | `/` を開く | ヘッダの見出しが「注文一覧」。市場ステータスに ● Pre-Market / ● Regular / ● After-Hours / ○ Closed のいずれかが表示される | 実装済 |
| LAY-03 | 既定モック | `/` でサイドバーの「顧客検索」を click | URL が `/customers/search` になり、ヘッダの見出しが「ページが見つかりません」に変わる。「顧客検索」だけが現在ページの表示になり、サイドバーは表示されたまま | 実装済 |
| LAY-04 | 既定モック | `/masters/users` を直接開く | サイドバーとヘッダの見出し「ページが見つかりません」が表示され、「ユーザマスタ」が現在ページの表示になる | 実装済 |
