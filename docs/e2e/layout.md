# 共通レイアウト（サイドメニュー / ヘッダ）

- 略号: `LAY`
- 画面: `src/components/layout/`（`AppLayout` / `AppSidebar` / `AppHeader`）
- テスト: `e2e/layout.spec.js`
- モック原本: `docs/mock/layout/masters-users.html`
- 単体側のシナリオ: [docs/unit/components-layout-app-layout.md](../unit/components-layout-app-layout.md)

全画面に出る共通部分の受け入れ条件。**個々の画面固有の要素（例: 注文一覧の「再読み込み」ボタン）は
その画面のシナリオ（[order-list.md](order-list.md)）で扱い、ここには書かない。**
メニューの遷移先はまだ大半が未実装のため、「ページが見つかりません」に落ちるのが正常。

サイドメニューは押し出し式で開閉する（閉じると画面外へ出て本文が全幅になる。幕は出さない）。
初期状態は **保存値 > 画面幅による既定**で決まり、保存値が無いときだけ 1024px 以下を閉とする。
**リサイズには追従しない**ので、幅を変えるテストは `page.goto()` より前に視点サイズを設定する。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| LAY-01 | 既定モック（幅 1280 / 開閉状態の保存なし） | `/` を開く | サイドバーに「米株発注システム」、見出し 顧客 / 注文 / マスタメンテ、リンク 15 件（顧客検索 … 残高補正）が表示される | 実装済 |
| LAY-02 | 既定モック | `/` を開く | ヘッダの見出しが「注文一覧」。市場ステータスに ● Pre-Market / ● Regular / ● After-Hours / ○ Closed のいずれかが表示される | 実装済 |
| LAY-03 | 既定モック | `/` でサイドバーの「顧客検索」を click | URL が `/customers/search` になり、ヘッダの見出しが「ページが見つかりません」に変わる。「顧客検索」だけが現在ページの表示になり、サイドバーは表示されたまま | 実装済 |
| LAY-04 | 既定モック | `/masters/fx` を直接開く | サイドバーとヘッダの見出し「ページが見つかりません」が表示され、「為替マスタ」が現在ページの表示になる | 実装済 |
| LAY-05 | 既定モック / 幅 1280 / 保存なし | `/` を開く | サイドメニューが表示され、メニューボタンが展開中を示す | 実装済 |
| LAY-06 | LAY-05 の状態 | メニューボタンを click | サイドメニューが見えなくなり、本文が画面左端まで広がる。もう一度 click すると元に戻る | 実装済 |
| LAY-07 | 幅 1280 で閉じた後 | ページを再読み込みする | 閉じたまま表示される | 実装済 |
| LAY-08 | 既定モック / 幅 1000 / 保存なし | `/` を開く | サイドメニューは閉じた状態で開く。メニューボタンを click すると開く | 実装済 |
| LAY-09 | 幅 1280 で閉じた状態 | Tab キーを繰り返し押す | フォーカスがサイドメニューのリンクに入らない | 実装済 |
