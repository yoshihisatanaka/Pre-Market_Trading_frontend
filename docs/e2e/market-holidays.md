# 海外休場日マスタ

- 略号: `MH`
- 画面: `src/views/MarketHolidayListView.vue`
- テスト: `e2e/market-holidays.spec.js`

`/masters/market-holidays` の受け入れ条件。ページ位置と検索条件は URL クエリ（`offset` / `date_from` /
`date_to` / `holiday_type`）を正としているため、**実ブラウザでの URL と画面の同期**をここで守る。
`?offset=7` のような端数の扱いや `?holiday_type=9` のような未知コードの無視など細かい分岐は
[docs/unit/views-market-holiday-list-view.md](../unit/views-market-holiday-list-view.md)
側で担保しているので、ここには書かない。既定モックは 2023〜2029 年の 56 件（1 ページ 50 件）。

一覧・検索（MH-01〜07）に加えて、ヘッダの「新規追加」からの登録（MH-08〜11）もこの画面の受け入れ条件に含む。
登録の既定モックは追加した行を保持するため、**登録後に件数が 1 増える**ところまで実ブラウザで見る
（モックの状態はページを開くたびに初期化される）。
行ごとの「削除」（MH-12〜16）もこの画面の受け入れ条件に含む。削除の既定モックも状態を保持するため、
確認モーダルを経て**削除後に件数が 1 減る**ところと、最終ページの最後の 1 件を消したときに
1 ページ前へ戻る URL の追従まで実ブラウザで見る。
休場区分（MH-17〜21）は一覧の列・検索条件・新規追加の 3 か所に現れるので、それぞれをここで守る。
既定モックの短縮取引はボクシングデーの 7 件（7 年分）だけなので、絞り込みの前後で件数が変わる。
