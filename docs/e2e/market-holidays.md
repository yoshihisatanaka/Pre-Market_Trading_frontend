# 海外休場日マスタ一覧

- 略号: `MH`
- 画面: `src/views/MarketHolidayListView.vue`
- テスト: `e2e/market-holidays.spec.js`

`/masters/market-holidays` の受け入れ条件。ページ位置と検索条件は URL クエリ（`offset` / `date_from` /
`date_to`）を正としているため、**実ブラウザでの URL と画面の同期**をここで守る。
`?offset=7` のような端数の丸めなど細かい分岐は [docs/unit/views-market-holiday-list-view.md](../unit/views-market-holiday-list-view.md)
側で担保しているので、ここには書かない。既定モックは 2023〜2029 年の 56 件（1 ページ 50 件）。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| MH-01 | 既定モック | `/` からサイドメニューの「海外休場日マスタ」を click | URL が `/masters/market-holidays` になり、ヘッダに見出し「海外休場日マスタ」と「再読み込み」ボタンが表示される。件数「56 件」、表に 50 行あり、1 行目に 2023-01-01 / 元日 が表示される | 実装済 |
| MH-02 | 既定モック（56 件） | 一覧を開いて「次のページ」を押す | URL に `offset=50` が付き、表が 6 行になる。1 行目に 2029-05-25 / メモリアルデー、ページ送りに「56 件中 51–56 件」が表示される | 実装済 |
| MH-03 | 既定モック | 日付（From）に 2025-01-01、日付（To）に 2025-12-31 を入れて「検索」を押す | URL に `date_from` と `date_to` が付き、件数「8 件」・表 8 行になり、すべての行の日付が 2025 年になる | 実装済 |
| MH-04 | MH-03 で絞り込んだ状態 | 「クリア」を押す | URL から検索条件が消え、件数が「56 件」に戻り、日付の入力欄が空になる | 実装済 |
| MH-05 | API が 500 を返す | 一覧を開く | エラーメッセージ（サーバーでエラーが発生しました。）と「再試行」ボタンが表示され、表は表示されない。検索フォームは表示されたまま | 実装済 |
| MH-06 | 休場日が 0 件 | 一覧を開く | 「該当する海外休場日はありません。」が表示され、行は無い。件数は「0 件」 | 実装済 |
| MH-07 | 既定モック | `/masters/market-holidays?offset=50` を直接開く | 2 ページ目の状態で表示される（表 6 行、ページ送りの「2」が現在ページ） | 実装済 |
