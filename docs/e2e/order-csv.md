# CSV一括注文

- 略号: `OC`
- 画面: `src/views/OrderCsvUploadView.vue`（`/orders/csv/upload`）
- テスト: `e2e/order-csv.spec.js`

CSV で注文をまとめて受け付ける画面（取込み → プレビュー → 受付完了）のうち、取込み画面の受け入れ条件。
プレビュー（`/orders/csv/preview`）と受付完了（`/orders/csv/complete`）は処理と一緒に作るので、
そのときにこのファイルへ行を足す（3 画面は 1 本の業務フローなので 1 ファイルにまとめる）。

「CSVフォーマット」カードは `GET /orders/csv-spec` の 4 状態（ローディング / エラー / 空 / データあり）を
ここで守る。既定モックは全 22 列（`src/mocks/fixtures/orderCsv.js`。バックエンドの列仕様の写し）で、
必須でないのは 7 列目の「指値単価」だけ（条件「指成区分がLO（指値）の場合は必須」が付く）。

**テンプレートDL・事前検証（内容を確認する）は処理が未実装**（UI だけ先に置いた段階）。
押しても何も起きないので、ここではボタンが在ることと、ファイル未選択で「内容を確認する」が押せないことだけを見る。
処理が入ったら下の `保留` の行を実装する。

列の値の整形（例の型を文字列に寄せる・condition の null を空にする）は api 層の単体テストの責務で、E2E に持ち込まない。
