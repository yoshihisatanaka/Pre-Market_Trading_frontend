# 注文照会

- 略号: `OI`
- 画面: `src/views/OrderInquiryListView.vue`
- テスト: `e2e/order-inquiry.spec.js`（未実装）

`/orders/inquiry` の受け入れ条件。元注文ごとに 1 行を出し、訂正履歴と自動分割（スライス）の明細を
その下に畳んで持つ一覧。検索条件は URL クエリ（`branch_code` / `account_number` / `symbol` / `status`）を
正としているため、**実ブラウザでの URL と画面の同期**をここで守る。

既定モック（`src/mocks/fixtures/orderInquiry.js`）は注文 14 行で、画面の行は元注文ごとにまとめた 8 行。
並びはサーバの既定（注文 ID の降順）で、まとまりが最初に現れた位置に出るので先頭行は `#35`
（子注文 `#45` が最も新しい）。件数の表示はサーバの `total`（注文の行数）なので「14 件」になる。

**画面はいま UI だけの段階。** 訂正・取消は押しても何も起きず、出来状況での絞り込みは URL に残るだけで
効かない（`TODO(処理実装)`）。ここではボタンが出る条件と開閉の見た目までを見る。処理が入ったら
OI-16 以降に行を足す。
