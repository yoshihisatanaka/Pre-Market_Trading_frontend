## 打ち手

### A. 実 API の確認は「早く・薄く・毎日」。網羅は 10/15 以降

実 API に当てて初めて露見した不備（id 未返却・クエリ改名・CA ステータス項目・日付上書き）が手戻りの主因なので、
**実 API を見ない期間は作らない**。ただし「画面ごとに実 API E2E を全シナリオ書く」は排他リソースの上で最も時間を食う。

| 何を | いつ | 見つかるもの |
|---|---|---|
| 契約テスト（`src/api/contract.spec.js`）+ `/api-spec-sync` | 毎朝 1 回（`/morning-check`） | 仕様レベルの食い違い。バックエンド不要 |
| 実 API スモーク（画面につき一覧 1 本 + 書き込み 1 本） | その画面の 3 軸が揃った当日 | ふるまいレベルの食い違い |
| 既存の `*.real-api.spec.js` 全件 | 毎朝 1 回 | バックエンド側の退行を 1 日で |
| 実 API シナリオの網羅 | 10/15 → 11/13 | 端の条件・エラー系 |

### B. 「待つ」を「契約を先に決める」に

1. 契約テスト: fixture ↔ `*Item` スキーマ、`src/api/` が送るパス・クエリ名・パスパラメータの型 ↔ `openapi.json`。
   既知の食い違いは `KNOWN_GAPS` に理由付きで載せ、解消したら落ちる（放置できない）
2. `/api-spec-sync` を毎朝の定型に。差分を 1 日分で止める
3. 成熟度 D の画面は fixture を契約提案として書き、3 軸を埋める（運用管理 3 画面がこれ）
4. バックエンドへの依頼を [api/requests.md](api/requests.md) に集約し、戻るセル数の順に並べる

### C. 検証コストを 1/3 に

`npm run verify`（1 コンテナで 3 検査）/ Stop フックは未コミットの変更ファイルだけを lint し、変更が無ければ Docker を起こさない /
E2E は画面略号で絞る / 検証は最後に 1 回。

### D. 人の承認を「シナリオ」から「差分」の 1 回に

テスト系サブエージェントの plan モードと承認手順を外す。人はコミット前の差分でシナリオ表も見る。
型に乗る画面のシナリオは `docs/e2e/_template-*.md` / `docs/unit/_template-*.md` から起こす。

### E. 画面の雛形を 1 コマンドで

`/new-screen <type> <kebab-name> <画面名>` が api / store / view / fixture / handler / docs / router / navigation を
既存の型に乗せて出す。残りの着手可能画面は検索一覧型 8 本・CRUD マスタ型 4 本で、いずれもこの型に乗る。

### F. マージの滞留と衝突を止める

実装コミットができた日に main へマージ（E2E `未着手` は warning で通る）/ `handlers/index.js` を画面別ファイルに分割（済）。

### H. 主キーの食い違いを `src/api/` に閉じ込める

一覧は全マスタが `ID` を返すが、PUT / DELETE のパスキーが ID なのは CA / 残高調整 / 手数料パターン / 手数料優遇の 4 種だけ。
残り 7 種は業務キー（問合せ中）。**パスキーは `openapi.json` に従い、変換は api 層の中だけ**で行う。画面・store は `id` のまま。
バックエンドが後で id に寄せたら api 層のパス 1 行を戻す。`*UpdateRequest` が業務キー項目を落としているので、業務キーは編集で変更不可。

### G. 仮定類型の 1 本目を早く通す

CSV一括注文 か 新規注文 を 1 本完成させ、`仮定` を `実測` に変える。仮定類型は 3 軸で 78 セルあり、倍率 1.5 なら 10/15 を越える。

## 効果の見立て

| 案 | 効く相手 | 見立て |
|---|---|---|
| C | Docker 待ち | 1 画面 5〜7 分 → 1〜2 分 |
| D | 承認待ち | 人の介在 3 回 → 1 回 |
| E | 参照読み・骨格書き | 2 画面/半日（09-17 実績）→ 3 画面/半日 |
| B-1/2 | 手戻り | 取り込み当日に検知 |
| B-3 | ブロック残 | 運用管理 30 セル（3 軸）を待たずに |
| 保留解除 + H | 実 API E2E | 4.5 セル |

C + D + E で 20〜25%、B-3 で残りを埋める見立て。A と B-1 は速度ではなく**後退**を止める（09-17 は達成セルが 2.0 減った）。
