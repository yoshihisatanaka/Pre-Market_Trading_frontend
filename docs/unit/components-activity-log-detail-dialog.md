# components/activityLog/ActivityLogDetailDialog（操作ログの詳細ダイアログ）

- 略号: `ALD`
- 対象: `src/components/activityLog/ActivityLogDetailDialog.vue`
- テスト: `src/components/activityLog/ActivityLogDetailDialog.spec.js`

操作ログ 1 件（`src/api/activityLogs.js` の `ActivityLog`）を読むだけのダイアログ。監査の記録なので
入力欄も保存ボタンも持たない。状態を持たず、閉じる操作は `close` の emit だけ。

props の `log` はテスト内で組み立てたアプリ内モデルを渡す。BaseModal が body へ Teleport するので
`global: { stubs: { teleport: true } }` を付ける。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| ALD-01 | `open: false` | マウントする | ダイアログが描画されない | 実装済 |
| ALD-02 | `open: true`・更新の行 | マウントする | タイトル「操作ログの詳細」と、操作日時（整形済み）・対象種別名・対象キー・操作区分のバッジ・操作者・履歴ID が出る | 実装済 |
| ALD-03 | 対象キーと操作者が空文字の行（一括処理） | マウントする | 対象キーと操作者が `—` になる | 実装済 |
| ALD-04 | `open: true` | マウントする | 入力欄（input / select / textarea）が無く、ボタンは「閉じる」だけ | 実装済 |
| ALD-05 | 変更項目が複数ある行 | マウントする | 変更項目がバッジで行の並びどおりに出る | 実装済 |
| ALD-06 | 変更項目が空の行 | マウントする | 「変更された項目はありません。」が出て、バッジの枠は出ない | 実装済 |
| ALD-07 | 差分を持つ行（値に `null` を含む） | マウントする | 差分の表に 項目 / 変更前 / 変更後 が行の並びどおりに出て、`null` は `—` | 実装済 |
| ALD-08 | 差分が空の行 | マウントする | 差分の表が出ない | 実装済 |
| ALD-09 | 変更前・変更後のデータを両方持つ行（更新） | マウントする | 変更前データ・変更後データの表が両方出て、それぞれ全項目が並ぶ。入れ子の値は JSON で出る | 実装済 |
| ALD-10 | 変更前データが `null` の行（登録） | マウントする | 変更前データの表は出ず、変更後データの表だけが出る | 実装済 |
| ALD-11 | 変更後データが `null` の行（削除） | マウントする | 変更後データの表は出ず、変更前データの表だけが出る | 実装済 |
| ALD-12 | `open: true` | 「閉じる」を click | `close` が 1 回 emit される | 実装済 |
| ALD-13 | `open: true`・`log: null` | マウントする | 落ちずにダイアログと「閉じる」だけが出て、詳細の本文は出ない | 実装済 |
| ALD-14 | 操作内容（`operationText`）を持つ行 | マウントする | 概要の「操作内容」（`activity-log-detail-operation-text`）に操作内容の文がそのまま出る | 実装済 |
| ALD-15 | 操作内容が空文字の行 | マウントする | 「操作内容」が `—` になる | 実装済 |
| ALD-16 | 注文の行（変更前・変更後データとも `null`、差分・変更項目が空、操作内容に変更の中身） | マウントする | 変更前データ・変更後データ・差分の表がどれも出ず、操作内容の文が出る | 実装済 |
