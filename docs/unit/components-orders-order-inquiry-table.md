# components/orders/OrderInquiryTable（注文照会の表）

- 略号: `OIT`
- 対象: `src/components/orders/OrderInquiryTable.vue`（中ほどのセルは `OrderInquiryCells.vue`）
- テスト: `src/components/orders/OrderInquiryTable.spec.js`

元注文ごとの行の下に、訂正履歴の行と自動分割の明細を畳んで持つ表。DataTable では行の下に行を
差し込めないので自前で描いている。セルの整形は `OrderInquiryCells` にあり、ここでまとめて見る
（単独では `<tr>` の外に置けないため）。props の `groups` は `src/api/orderInquiry.js` の `OrderInquiryGroup`。
`canOrder`（発注権限）は既定 false で、true のときだけ行に「訂正」「取消」を出す。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| OIT-01 | 1 件の行を渡す | マウントする | 列見出しが 注文ID / 部店 / 口座番号 / 顧客名 / 銘柄 / 売買 / 数量 / 指値／成行 / 価格 / 出来数量 / 未出来残数量 / 約定代金（USD） / 約定代金（円貨） / 市場区分 / 出来状況 / 送信日時 / 受注日時 / 操作 の 18 列になる | 実装済 |
| OIT-02 | `history` が空の行 / 2 件の行 | マウントする | 注文 ID が `#35` のように `#` 付きで出る。「+」と「訂正 N回」は history がある行にだけ出て、2 件なら「訂正 2回」 | 実装済 |
| OIT-03 | `history` が 2 件の行 | 「+」を押す → もう一度押す | 訂正履歴の行が 2 行開き、ボタンが「−」・`aria-expanded="true"` になる。2 回目で閉じて「+」・`false` に戻る | 実装済 |
| OIT-04 | `history` が 2 件の行を開いている | — | 1 行目の銘柄の下に「原注文（訂正済）」、2 行目に「第1回訂正」と出る | 実装済 |

| OIT-09 | `filledQuantity` が 0・`canceledQuantity` が 40 の行 | マウントする | 出来数量と約定代金が「—」、数量の下に「取消 40」が添えられる | 実装済 |

| OIT-11 | `vwap` が true の行 | マウントする | 市場区分の下に「VWAP」と添えられる | 実装済 |
| OIT-12 | どの行でも | マウントする | 送信日時は常に「—」（API に項目が無い） | 実装済 |
