# composables/useSidebarToggle（サイドメニューの開閉状態）

- 略号: `UST`
- 対象: `src/composables/useSidebarToggle.js`
- テスト: `src/composables/useSidebarToggle.spec.js`
- 使う側: [components-layout-app-layout.md](components-layout-app-layout.md)
- E2E 側のシナリオ: [docs/e2e/layout.md](../e2e/layout.md)

サイドメニューは**押し出し式**（閉じると画面外へ出て本文が全幅になる）。
この composable は開閉状態だけを持ち、見た目は持たない。

初期値の決め方が仕様の要。**保存値 > 画面幅による既定**で、

- `localStorage` に保存値があればそれに従う（画面幅は見ない）
- 保存値が無いときだけ画面幅で決め、`SIDEBAR_BREAKPOINT`（1024px）**以下**なら閉
- **リサイズには追従しない。** 幅を見るのは初期化の 1 回だけで、手で開いたものを
  ウィンドウ操作で勝手に畳まない（追従させると「選択を保存し再訪時も維持する」と矛盾する）

`localStorage` が使えない環境（プライベートモード等）でも開閉そのものは成立させる。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| UST-01 | 保存値なし / 幅 1280 | `useSidebarToggle()` を呼ぶ | 開いた状態で始まる | 実装済 |
| UST-02 | 保存値なし / 幅 1024 | 呼ぶ | 閉じた状態で始まる（1024 は「以下」側） | 実装済 |
| UST-03 | 保存値「閉」/ 幅 1280 | 呼ぶ | 閉じた状態で始まる（保存値が画面幅より優先） | 実装済 |
| UST-04 | 保存値「開」/ 幅 800 | 呼ぶ | 開いた状態で始まる | 実装済 |
| UST-05 | 保存値なし / 幅 1280 | `toggle()` を 2 回呼ぶ | 毎回反転し、その都度保存される | 実装済 |
| UST-06 | 保存値が壊れている（`'yes'`） | 呼ぶ | 保存値を無視し、画面幅による既定で始まる | 実装済 |
| UST-07 | localStorage の読み書きが例外を投げる | 呼んで `toggle()` | 例外を投げず、画面幅による既定から開閉できる | 実装済 |
