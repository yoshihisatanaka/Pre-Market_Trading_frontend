# utils/format（表示用の整形）

- 略号: `FMT`
- 対象: `src/utils/format.js`
- テスト: `src/utils/format.spec.js`

金額・数量・日時を表示用の文字列に直す純関数。画面と一覧セルの見た目がここで決まる。

守るのは 2 つ。

- **空値の表現が `'—'` でそろっていること。** 一覧の空欄は「値が無い」ことが読み取れないので、
  どの関数も `null` / `undefined` / `NaN` を `'—'` にする
- **`0` を空値として扱わないこと。** 前日終値や出来高の `0` と「まだ取得していない」は別の意味で、
  api 層（[api-stocks.md](api-stocks.md)）が `null` のまま通してくる区別をここで消さない

`formatUsd` と `formatUsdUnit` の違いは見た目だけ（`$227.16` / `227.16 ドル`）。
どちらを使うかは画面の指定で決まるので、優劣は無い。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| FMT-01 | — | `formatUsd(227.16)` を呼ぶ | 通貨記号付き・小数 2 桁の `'$227.16'` が返る | 実装済 |
| FMT-02 | — | `formatUsd(0)` を呼ぶ | `'$0.00'` が返る（`0` を空値にしない） | 実装済 |
| FMT-03 | — | `formatUsd()` を `null` / 未設定 / `NaN` で呼ぶ | いずれも `'—'` | 実装済 |
| FMT-04 | — | `formatUsdUnit(227.16)` を呼ぶ | `'227.16 ドル'` が返る（通貨記号を使わない） | 実装済 |
| FMT-05 | — | `formatUsdUnit()` を小数第 1 位までの値と 100 万超の値で呼ぶ | 小数 2 桁に揃い、整数部は 3 桁区切りになる（`'419.80 ドル'` / `'1,234,567.50 ドル'`） | 実装済 |
| FMT-06 | — | `formatUsdUnit(0)` を呼ぶ | `'0.00 ドル'` が返る | 実装済 |
| FMT-07 | — | `formatUsdUnit()` を `null` / 未設定 / `NaN` で呼ぶ | いずれも `'—'` | 実装済 |
| FMT-08 | — | `formatQuantity()` を 8 桁の整数と `0` で呼ぶ | 3 桁区切りの `'43,820,000'` と `'0'` が返る | 実装済 |
| FMT-09 | — | `formatQuantity()` を `null` / 未設定 / `NaN` で呼ぶ | いずれも `'—'` | 実装済 |
| FMT-10 | — | `formatDateTime('2026-08-20T09:30:00')` を呼ぶ | `YYYY/MM/DD HH:mm` の形で、渡した年月日時分がそのまま出る（タイムゾーン指定の無い文字列は現地時刻として読む） | 実装済 |
| FMT-11 | — | `formatDateTime()` を空文字 / `null` / 未設定 / 日付にならない文字列で呼ぶ | いずれも `'—'`（`Invalid Date` を画面に出さない） | 実装済 |
