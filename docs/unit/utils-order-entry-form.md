# utils/orderEntryForm（新規注文フォームの純関数）

- 略号: `NOF`
- 対象: `src/utils/orderEntryForm.js`
- テスト: `src/utils/orderEntryForm.spec.js`

入力中の整形・画面での検証・送る値の組み立て・期間指定の選択肢・概算金額・確認画面の読み上げ。
日付は**すべて `today` / `now` 引数で固定する**（テストの実行日に依存させない）。基準日は 2026-09-29（火）。
検証の文言はモックリポジトリ `validators/order_validator.py` の原文で、ファイル内の `MESSAGES` は公開されて
いないため、テストでは文言そのものを期待値に書く（文言が仕様）。
