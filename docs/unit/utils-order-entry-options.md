# utils/orderEntryOptions（新規注文の選択肢）

- 略号: `NOP`
- 対象: `src/utils/orderEntryOptions.js`
- テスト: `src/utils/orderEntryOptions.spec.js`

新規注文（外株注文入力）の選択肢のうち、画面が決めること（コードの並び・選べる値の絞り込み・配色や見出し）と
欄の無い固定値。**表示名はコードマスタ（`GET /codes`）から引く**（`stores/codes.js`）ので、このファイルは名称を持たない。
期待する名称はフィクスチャ（`src/mocks/fixtures/codes.js`。実 API の写し）から引く。守るのは次の 3 つ。

- 画面が送るコードが `src/utils/apiEnums.js` の `*_VALUES`（`openapi.json` の enum の写し）に含まれ、
  コードマスタに名称があること。enum から値が消えたり、コードマスタに無いコードを並べたりしたら、ここで落ちる
- 向きを取り違えやすい値（売買区分の 1 / 3、指成区分の MO / LO）と、コード順と違う並び（買 → 売、成行 → 指値）
- フェーズ 2 の注文区分を見せるが選ばせない飾り（`decorateOptions`）
