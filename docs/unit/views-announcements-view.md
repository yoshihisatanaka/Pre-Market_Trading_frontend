# views/AnnouncementsView（お知らせ管理画面）

- 略号: `ANV`
- 対象: `src/views/AnnouncementsView.vue`
- テスト: `src/views/AnnouncementsView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、
**お知らせ本体と履歴で別々の 4 状態**、保存の入力検証・サーバの拒否（400 / 422 / 409）の出し分け、
履歴のページングを守る。
この画面は URL クエリを使わない（履歴のページ位置はストアが持つ）。期待値はフィクスチャと
`ANNOUNCEMENT_HISTORY_PAGE_SIZE` から導く。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| ANV-01 | 応答を握ったまま | マウントする | お知らせと履歴の両方にローディングが出て、フォーム・履歴の表・空表示・エラーは出ない | 実装済 |
| ANV-02 | `GET /operations/announcements` が 500 | マウントする | 理由と「再試行」が出て、フォームは出ない。履歴は表で表示される | 実装済 |
| ANV-03 | レスポンスボディが `null` | マウントする | 「お知らせが登録されていません。」が出て、フォームは出ない | 実装済 |
| ANV-04 | 既定モック | マウントする | フォームが出て、表示チェックが現在の表示フラグ、本文欄が現在の本文、ヒントが残り文字数になる | 実装済 |
| ANV-05 | ANV-02 の状態 | 「再試行」を押す（応答は既定に戻す） | フォームが表示される | 実装済 |
| ANV-06 | 既定モック | マウントする | 履歴の表に 1 ページぶんの行が出て、先頭行が履歴フィクスチャ先頭の操作日時・操作区分名・本文・操作者、ページャーが「全件中 1–PAGE_SIZE 件」 | 実装済 |
| ANV-07 | 履歴 API が 500 | マウントする | 履歴に理由と「再試行」が出てページャーは出ない。フォームは使え、保存すると成功文言が出る | 実装済 |
| ANV-08 | 履歴が 0 件の応答 | マウントする | 「お知らせ履歴はありません。」が出て、表とページャーは出ない | 実装済 |
| ANV-09 | ANV-07 の状態 | 履歴の「再試行」を押す（応答は既定に戻す） | 履歴の表が表示される | 実装済 |
| ANV-10 | 既定モック | ページャーの 2 を押す | `offset=PAGE_SIZE` で取得し、残りの件数の行とその範囲の件数表示が出る | 実装済 |
| ANV-11 | 既定モック | 本文を書き換えて「お知らせを更新」 | 応答の成功文言がそのまま通知に出て、本文欄は保存した値、履歴の件数が 1 増えて先頭行が新しい本文になる | 実装済 |
| ANV-12 | 履歴の 2 ページ目を表示中 | 本文を書き換えて保存 | 履歴が先頭ページに戻る | 実装済 |
| ANV-13 | 既定モック | 表示チェックを外し本文を空にして保存 | 非表示の成功文言が出て、履歴の先頭行が「非表示」で本文が「—」 | 実装済 |
| ANV-14 | 既定モック | 何も変えずに保存 | 「変更はありません。」が通知に出て、履歴の件数は変わらない | 実装済 |
| ANV-15 | 表示 ON | 本文を空白だけにして保存 | 本文の直下に「お知らせを表示するには本文を入力してください。」が出て、PUT を送らない。通知は出ない | 実装済 |
| ANV-16 | PUT が 400 | 保存 | フォーム先頭に応答の `detail` が出て、入力は残り、通知は出ない | 実装済 |
| ANV-17 | 既定モック | 本文を 501 文字にして保存 | フォーム先頭に 422 の理由（`本文` の上限超え）が出て、入力は残る | 実装済 |
| ANV-18 | 既定モック | マウントする・本文を入力する | 本文欄の `maxlength` が 500 で、ヒントの残り文字数が入力に追従する | 実装済 |
| ANV-19 | 表示後に他の担当者がお知らせを更新 | 本文を書き換えて保存 | フォーム先頭に 409 の理由が出て、入力は残り、通知は出ない | 実装済 |
| ANV-20 | PUT の応答を握ったまま | 保存を 2 回続けて送る | PUT は 1 回だけ送られ、ボタンは「更新中…」で押せない。応答後に成功文言が出る | 実装済 |
| ANV-21 | 既定モック（通常運用） | マウントする | 現在の運用状態が「通常運用」で、発注停止の警告は出ない | 実装済 |
| ANV-22 | バナーが発注停止中（INCIDENT） | マウントする | 現在の運用状態が「発注停止中」で、発注停止の警告が出る。フォームは表示される | 実装済 |
| ANV-23 | バナー API が 500 | マウントする・保存する | 現在の運用状態が「—」で警告は出ない。フォームは表示され、保存すると成功文言が出る | 実装済 |
