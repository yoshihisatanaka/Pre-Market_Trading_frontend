# views/BalanceAdjustmentListView（残高マスタ一覧画面）

- 略号: `BLV`
- 対象: `src/views/BalanceAdjustmentListView.vue`
- テスト: `src/views/BalanceAdjustmentListView.spec.js`

URL クエリの端数・未知の値の扱いや、2 段階モーダルの遷移といった細かい分岐はここが担保する。
実ブラウザでの URL 同期と一覧の見た目は [docs/e2e/balance-adjustments.md](../e2e/balance-adjustments.md)（`BA`）側。

この画面はヘッダ（`#topbar-actions`）に操作を差し込まない。「新規保有を追加」は画面モックどおり
一覧カードの見出し（`MasterListCard` の actions スロット）に置く。モーダル（`BaseModal`）は
`Teleport to="body"` を使うので、マウント時に `global: { stubs: { teleport: true } }` が要る。
見出し右の権限表示は `GET /auth/me`（`stores/currentOperator.js`）から出す。
