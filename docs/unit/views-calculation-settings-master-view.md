# views/CalculationSettingsMasterView（仮計算マスタ画面）

- 略号: `PCV`
- 対象: `src/views/CalculationSettingsMasterView.vue`
- テスト: `src/views/CalculationSettingsMasterView.spec.js`

単一レコードの設定画面で、構成はスライス基準マスタ（[views-slice-criteria-master-view.md](views-slice-criteria-master-view.md)）と同じ
「現在の設定」と「設定変更」の 2 カード。一覧の雛形（`_template-view.md`）の検索・ページングの行は当てはまらないので、
4 状態とこの画面固有の換算・入力検証・保存の行だけを置く。

ストアは API の単位（取引所税率は比率 `0.00002`、現地手数料率は bp `10`）で持ち、画面は % で見せる。
**換算はこの画面の責務**: 表示と入力欄の初期値は 比率 × 100 / bp ÷ 100、保存時は逆向きに戻し、
比率は小数第 10 位・bp は小数第 4 位に丸めて送る。スプレッド（円/USD）と NISA為替上乗せ率（%）は換算しない。

入力の検証は「空欄」「桁あふれ」（取引所税・現地手数料率は小数第 6 位、スプレッド・NISA は第 4 位まで）だけを
画面で行い、項目の下に出して PUT を送らない。値の範囲はサーバ（MSW）の 422 に任せ、理由を
`calc-settings-save-error` に出す。閲覧のみの出し分けは無い（ルートの権限で開けた人は更新できる）。
画面は Teleport を使っていないが、他の画面テストと同じ作法で `global: { stubs: { teleport: true } }` を付けてマウントする。
