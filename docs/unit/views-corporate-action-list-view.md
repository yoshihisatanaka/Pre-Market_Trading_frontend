# views/CorporateActionListView（CAマスタ一覧画面）

- 略号: `CAV`
- 対象: `src/views/CorporateActionListView.vue`
- テスト: `src/views/CorporateActionListView.spec.js`

実際の Pinia ストア + vue-router + MSW(node) を通して、
**4 状態の出し分け**と「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。

実ブラウザでの URL 同期は [docs/e2e/ca.md](../e2e/ca.md)（`CA`）が別に見る。
こちらは E2E では安定して観測できないもの（過渡状態・手で書き換えられた URL クエリ・
応答の差し替え）を担保する。分担は次のとおり。

| 論点 | E2E | 単体 | 理由 |
|---|---|---|---|
| ページ送り・検索の URL 同期 | CA-02 / 03 / 04 | CAV-11 / 12 | 実ブラウザの履歴まで見るのは E2E、条件の受け渡しは単体 |
| 未知の `ca_type` | — | CAV-14 | 画面の導線からは起こらない（手で URL を書いたときだけ） |
| `CA種別名` が欠けた応答 | — | CAV-06 | 応答の差し替えが要る。実 API は常に付けて返す |
| 表示件数の倍数でない `offset` | — | CAV-10 | 同上。画面の導線からは起こらない |

この画面は**読むだけ**で、新規追加・編集・削除の導線を持たない（CAV-16）。
持つ画面の例は [views-blackout-date-list-view.md](views-blackout-date-list-view.md)。

期待値はフィクスチャ（`src/mocks/fixtures/ca.js`）と `CA_PAGE_SIZE` から導く。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| CAV-01 | 既定モック | マウント直後（応答前）を見る | 「読み込み中…」が出て、表も空状態も出ない | 実装済 |
| CAV-02 | 既定モック | マウントして応答を待つ | 件数がフィクスチャの全件数で、表の行が `CA_PAGE_SIZE` 件。1 行目の銘柄コード・CA種別名・日付・比率・備考がフィクスチャの先頭行と一致する | 実装済 |
| CAV-03 | 既定モック | 表の列見出しを読む | `銘柄` / `CA種別` / `権利付最終日` / `効力発生日` / `支払日` / `比率` / `備考` がこの順に並ぶ。ステータス列と操作列は無い | 実装済 |
| CAV-04 | 既定モック（ユーザー操作フラグ 1 と 0 の行を含む） | マウントして応答を待つ | フラグ 1 の行にだけ `is-user-modified` が付き、0 の行には付かない | 実装済 |
| CAV-05 | 支払日が未設定の行がある | マウントして応答を待つ | その行の支払日セルに `—` が出る（空欄にしない） | 実装済 |
| CAV-06 | API が `CA種別名` を持たない行を返す | マウントして応答を待つ | CA種別セルにコードから引いた表示名が出る（コードの数字をそのまま出さない） | 実装済 |
| CAV-07 | API が 0 件を返す | マウントして応答を待つ | 「該当するCAはありません。」が出て、表は描画されない | 実装済 |
| CAV-08 | API が 500 を返す | マウントして応答を待つ | エラーの理由と「再試行」ボタンが出て、表も空状態も出ない | 実装済 |
| CAV-09 | API が 500 を返した後、正常応答に戻る | 「再試行」を click | 表が描画され、エラー表示が消える | 実装済 |
| CAV-10 | 既定モック。`?offset=7`（表示件数の倍数でない） | マウントして応答を待つ | 丸めずその位置から `CA_PAGE_SIZE` 件が出る | 実装済 |
| CAV-11 | 既定モック | ページ送りの「2」を click | URL に `offset` が乗り、表が 2 ページ目に入れ替わる | 実装済 |
| CAV-12 | 既定モック | 銘柄コードと CA種別を入れて「検索」を click | URL に `stock_code` / `ca_type` が乗り、表が絞り込まれる。`offset` は付かない（1 ページ目に戻る） | 実装済 |
| CAV-13 | 既定モック。絞り込み済み | 「クリア」を click | URL クエリが空になり、全件に戻る | 実装済 |
| CAV-14 | `?ca_type=999`（実在しないコード） | マウントして応答を待つ | 条件なしとして捨てられ、全件が出る。セレクトは「-- すべて --」のまま | 実装済 |
| CAV-15 | API が 0 件 / 500 / 正常 のいずれか | マウントして応答を待つ | 説明バナーと検索カードはどの状態でも消えない（0 件やエラーのときこそ条件を直したい） | 実装済 |
| CAV-16 | 既定モック | ヘッダと表の操作を見る | ヘッダに「再読み込み」だけがあり「新規追加」は無い。行にも編集・削除のボタンが無い | 実装済 |
