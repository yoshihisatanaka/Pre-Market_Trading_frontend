# views/CustomerCalculationView（顧客詳細の仮計算タブ）

- 略号: `CCV`
- 対象: `src/views/CustomerCalculationView.vue`
- テスト: `src/views/CustomerCalculationView.spec.js`

**いまは見た目だけの画面。** 入力欄は値を持つだけで、「仮計算を実行」は何もしない（`POST /calculations` は未接続）。
結果のカードは枠だけで、金額は「—」。API を読まないので 4 状態もまだ無い。
ここで守るのは、URL クエリからの引き継ぎ（`utils/calculationQuery.js`）が入力欄の初期値になることと、
売買・預り区分の選択で結果のカードの見出しと行が切り替わることだけ。仮計算をつなぐときに、実行・エラー・結果の表示を足す。

枠（`CustomerDetailView`）は通さず、この画面だけをテスト用ルータの `/customers/:customerId/calculations` でマウントする。
国内約定日の既定（今日）を固定するため、`Date` だけを偽の時計にする（2026-10-06）。
