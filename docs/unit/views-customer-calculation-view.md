# views/CustomerCalculationView（顧客詳細の仮計算タブ）

- 略号: `CCV`
- 対象: `src/views/CustomerCalculationView.vue`
- テスト: `src/views/CustomerCalculationView.spec.js`

「仮計算を実行」で入力を画面で検証し、通れば `POST /calculations`（`stores/calculation.js`）を呼んで、
返った値を結果のカードに出す。計算はすべてサーバが行い、画面は値を書式に流すだけ（`utils/calculationForm.js`）。
入力の不備は項目の直下（FormField の `role="alert"`）に出し、API は呼ばない。
口座番号は枠のストア（`stores/customerDetail.js` の `customer.accountNumber`）から取る。

結果のカードは 4 状態を出し分ける。

| 状態 | 見出し（`customer-calc-result-caption`） | 金額 |
|---|---|---|
| 未実行 | `買付概算 ／ 未実行`（売りなら `売却概算`） | 「—」。行は入力中の売買・預り区分に合わせる |
| 実行中 | `… ／ 計算中…`。送信ボタンは disabled + `aria-busy`、カードも `aria-busy` | 「—」 |
| 失敗 | `… ／ 計算できませんでした`。理由は `customer-calc-error` | 「—」 |
| 結果あり | `売却概算 ／ AAPL 10株` の形 | 応答の値。サーバの warnings は `customer-calc-warnings` |

明細行は 外貨約定代金 / 現地費用合計 / 取引所税 / 適用為替 / 円換算精算金額 / 国内手数料 / 消費税 の 7 行。
買い × 成長投資枠 のときだけ「NISA仮計算適用為替」「NISA使用予定額」が円換算精算金額の後ろに入って 9 行になる。
概算損益の枠は、未実行時は 売り × 特定 のときだけ（値「—」）、結果ありのときはサーバが概算譲渡損益を返したときだけ出る。

枠（`CustomerDetailView`）ごと `/customers/:customerId/calculations` からマウントし、実 Pinia + テスト用ルータ + MSW(node) を通す。
顧客 ID 1（口座番号 1230001）を開く。国内約定日の既定（今日）を固定するため、`Date` だけを偽の時計にする（2026-10-06）。
結果の期待値は既定モック（`mocks/fixtures/calculations.js` の `buildCalculationResponse`）に同じ本文を渡して導く。
