# views/DreamStatusListView（Dream登録状況画面）

- 略号: `DSV`
- 対象: `src/views/DreamStatusListView.vue`
- テスト: `src/views/DreamStatusListView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。`global: { stubs: { teleport: true } }` を付ける
（エラー内容のポップアップと STS変更ダイアログも wrapper 内に描かせる）。

この画面に固有の、取り違えやすい点を 4 つ固定する。

- **エラー内容は常設の列ではなくポップアップ。** 登録失敗・取消失敗の行だけ、状況の文字に触れると出る。
  見出しは登録失敗が「Dream登録エラー詳細」、取消失敗が「Dream取消エラー詳細」（DSV-07 / DSV-08）
- **STS変更はサーバの `STS変更可` の行だけ。** それ以外の行は「変更不可」の文字（DSV-09）
- **プルダウンで選んでもすぐには変えない。** 確認ダイアログを開き、キャンセルするとプルダウンも
  「いまの状況」に戻る（DSV-10 / DSV-11）。送信はまだ繋いでいない
- **URL のクエリ名はバックエンドのクエリ名と別。** 画面は `account_number` / `dream_status` /
  `registered_from` / `registered_to` / `dream_ref` を使い、api 層が `account_no` などに言い換える

期待値はフィクスチャ（`src/mocks/fixtures/dreamStatus.js`）と `DREAM_STATUS_PAGE_SIZE` から導く。
