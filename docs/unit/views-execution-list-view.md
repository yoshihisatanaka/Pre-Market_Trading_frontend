# views/ExecutionListView（約定照会画面）

- 略号: `EXV`
- 対象: `src/views/ExecutionListView.vue`
- テスト: `src/views/ExecutionListView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フロー、件数カードの出し分けを守る。
`global: { stubs: { teleport: true } }` を付ける。
実ブラウザでの URL 同期は E2E が見る。こちらは E2E では安定して観測できないもの（過渡状態・手で書き換えられた
URL クエリ・応答の差し替え）を担保する。

出来状況の選択肢はコードマスタ `約定出来状況` から来る。App.vue はコードマスタを
読み終えてから画面を描くので、テストもマウント前にコードマスタを読む。
