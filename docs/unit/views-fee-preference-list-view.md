# views/FeePreferenceListView（手数料優遇マスタ一覧画面）

- 略号: `FPV`
- 対象: `src/views/FeePreferenceListView.vue`
- テスト: `src/views/FeePreferenceListView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。`global: { stubs: { teleport: true } }` を付ける。
実ブラウザでの URL 同期は E2E（[fee-preferences.md](../e2e/fee-preferences.md)）が見る。こちらは E2E では
安定して観測できないもの（過渡状態・手で書き換えられた URL クエリ・応答の差し替え）と、画面固有の分岐
（数値の形の検査・警告の「続行」・変更の応答の警告・適用されない方式の列）を担保する。
入力項目は `src/components/feePreference/FeePreferenceFormFields.vue` が描くので、その挙動もここで見る。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| FPV-01 | 応答を握ったまま | マウントする | ローディングが表示され、表と空表示とエラーは出ない | 実装済 |
| FPV-02 | `GET /masters/fee-preferences` が 500 | マウントする | エラーの理由と「再試行」が表示され、表は出ない | 実装済 |
| FPV-03 | 0 件の応答 | マウントする | 「該当する手数料優遇はありません。」が表示され、表は出ない | 実装済 |
| FPV-04 | 既定モック | マウントする | 件数と 1 ページぶんの行が表示され、1 行目がフィクスチャ先頭行（口座番号の昇順）の口座番号・顧客名になる | 実装済 |
| FPV-05 | FPV-02 の状態 | 「再試行」を押す（応答は既定に戻す） | 一覧が表示される | 実装済 |
| FPV-06 | `?offset=50` で開く | マウントする | 2 ページ目の行数（2 行）と「52 件中 51–52 件」が出る | 実装済 |
| FPV-07 | 既定モック | 口座番号に値を入れて「検索」 | ルートのクエリが `account_no=値` になり、その条件で再取得される | 実装済 |
| FPV-08 | `?fee_pattern=ZZ`（未知の値） | マウントする | 落ちずに条件なしとして扱い、全件（52 件）が表示される。手数料パターンの検索欄は未選択 | 実装済 |
| FPV-09 | `?fee_pattern=default` | マウントする | 手数料パターンの検索欄が「デフォルト」になり、API へ `fee_pattern=`（空文字）で送られる。表の全行の手数料パターンが「デフォルト」 | 実装済 |
| FPV-10 | 既定モック | 2 ページ目で絞り込みを変える | `offset` が消えて 1 ページ目から表示される | 実装済 |
| FPV-11 | 追加モーダルを開いた状態 | 口座番号 `12a`、掛目 `abc` を入れて「追加」 | 口座番号と掛目の直下に理由が出て、事前検証も登録も呼ばれない | 実装済 |
| FPV-12 | 追加モーダルを開いた状態 | 口座番号 `2340014`、手数料パターン `E` で「追加」→ 続けて「続行」 | 1 回目は警告の箇条書きが出て送信ボタンが「続行」になり、モーダルは閉じない。2 回目でモーダルが閉じ、成功メッセージが出て件数が 1 増える | 実装済 |
| FPV-13 | 警告が出た状態（FPV-12 の 1 回目） | 入力を 1 つ変える | 警告が消え、送信ボタンが「追加」に戻る | 実装済 |
| FPV-14 | 既定モック | 1 行目の「編集」→ ベイシス `30`・掛目 `80` にして「更新」 | モーダルが閉じ、成功メッセージと、変更の応答が返した警告（掛目が使われない旨）が注意の表示に出る | 実装済 |
| FPV-15 | 既定モック | 1 行目（為替スプレッド 0・掛目未設定）の「編集」を押す | 為替スプレッドの欄が `0`、掛目の欄が空で開く（0 と未設定を混ぜない）。口座番号の欄は読み取り専用ではない | 実装済 |
| FPV-16 | 既定モック | 一覧を表示する | ベイシス方式の行は手数料パターン・掛目・手数料 下限〜上限のセルが淡色（`is-unused`）、パターン方式の行はベイシス 下限〜上限のセルが淡色になる | 実装済 |
