# views/FxRateMasterView（為替マスタ画面）

- 略号: `FXV`
- 対象: `src/views/FxRateMasterView.vue`
- テスト: `src/views/FxRateMasterView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**
（`fx-loading` / `fx-error` / `fx-empty` / `fx-current`）と「レート更新」モーダル（`MasterFormDialog`、
`fx-update-*`）の入出力を守る。`global: { stubs: { teleport: true } }` を付ける。
一覧・検索が無い単一レコードの画面なので、URL クエリとの同期は無い（雛形の XXV-06〜10 は該当しない）。

「今日」は `vi.useFakeTimers({ toFake: ['Date'] })` で固定する（ストアの [stores-fx-rates.md](stores-fx-rates.md) と同じ導きかた）。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| FXV-01 | 既定モック | マウント直後 | ローディングが出て、現在レート・空表示・エラーは出ない。「レート更新」は押せない | 実装済 |
| FXV-02 | latest が 500 | マウントする | エラーの理由と「再試行」が出て、現在レートは出ない。「レート更新」は押せない | 実装済 |
| FXV-03 | latest が 404 | マウントする | 未登録の空表示が出て、現在レートは出ない。「レート更新」は押せる | 実装済 |
| FXV-04 | 既定モック | マウントする | 現在レートが最新行の値を小数 2 桁で、基準日が 'YYYY-MM-DD'、最終更新が整形済みの更新日時と更新者で出る | 実装済 |
| FXV-05 | latest が 1 回だけ 500 | 「再試行」を押す | エラーが消えて現在レートが出る | 実装済 |
| FXV-06 | 既定モック | 「レート更新」を押す | モーダルが開き、入力欄の初期値が現在レート、送信ボタンの文言が「更新」 | 実装済 |
| FXV-07 | モーダルを開いた状態 | 入力を空にして送信 | 「レートを入力してください。」が出て、事前検証のリクエストを送らない | 実装済 |
| FXV-08 | 既定モック、今日の行が無い | 新しいレートを入れて送信 | モーダルが閉じ、「USD/JPY のレートを <小数 2 桁> 円に更新しました。」が出て、現在レートと基準日（= 今日）が入れ替わる | 保留 |
| FXV-09 | 既定モック、今日 = 最新行の基準日 | 新しいレートを入れて送信 | モーダルが閉じて完了の文言が出て、現在レートが入れ替わる。基準日は変わらない | 保留 |
| FXV-10 | 既定モック | 一般的な範囲から外れるレートで送信 | 警告が出てモーダルは開いたまま、送信ボタンが「続行」、現在レートは変わらない | 保留 |
| FXV-11 | FXV-10 の状態 | そのまま「続行」を押す | 保存されてモーダルが閉じ、現在レートがそのレートになる | 保留 |
| FXV-12 | FXV-10 の状態 | 入力値を変える | 警告が消え、送信ボタンが「更新」に戻る | 保留 |
| FXV-13 | validate が `valid: false` | 送信 | 事前検証の理由がモーダル内に出て、モーダルは開いたまま | 保留 |
| FXV-14 | 今日 = 最新行の基準日、PUT が 409 | 送信 | サーバの文言がモーダル内のエラーに出て、モーダルは開いたまま、現在レートは変わらない | 保留 |
| FXV-15 | 既定モック | レート 0 で送信 | 「為替レート: 」を前置した 422 の理由がモーダル内のエラーに出る | 保留 |
| FXV-16 | 既定モック | モーダルを開いて「キャンセル」 | モーダルが閉じ、現在レートは変わらず完了の文言も出ない | 実装済 |
| FXV-17 | latest が 404 | 「レート更新」を押す → レートを入れて送信 | 入力欄の初期値は空。送信後に空表示が消えて現在レートが出る | 保留 |

> **保留の理由（2026-09-29）**: FXV-08〜15 / FXV-17 は、入力欄を書き換えてから送信すると
> `FxRateMasterView.vue` の `submitUpdate` が TypeError で止まる不具合があるため保留にしてある。
> 入力欄が `type="number"` なので、Vue の `v-model` が入力値を Number に変換し、
> `rateInput.value.trim()` が「trim is not a function」になる。テストは `it.skip` で書いてあり、
> 不具合が直ったら skip を外して「実装済」にする。
