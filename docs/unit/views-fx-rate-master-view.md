# views/FxRateMasterView（為替マスタ画面）

- 略号: `FXV`
- 対象: `src/views/FxRateMasterView.vue`
- テスト: `src/views/FxRateMasterView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**
（`fx-loading` / `fx-error` / `fx-empty` / `fx-current`）と「レート更新」モーダル（`MasterFormDialog`、
`fx-update-*`）の入出力を守る。`global: { stubs: { teleport: true } }` を付ける。
一覧・検索が無い単一レコードの画面なので、URL クエリとの同期は無い（雛形の XXV-06〜10 は該当しない）。

「今日」は `vi.useFakeTimers({ toFake: ['Date'] })` で固定する（ストアの [stores-fx-rates.md](stores-fx-rates.md) と同じ導きかた）。
