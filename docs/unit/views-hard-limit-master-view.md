# views/HardLimitMasterView（ハードリミットマスタ画面）

- 略号: `HLV`
- 対象: `src/views/HardLimitMasterView.vue`
- テスト: `src/views/HardLimitMasterView.spec.js`
- E2E 側のシナリオ: [docs/e2e/hard-limits.md](../e2e/hard-limits.md)

ストアが持つ比率（`0.05`）と画面の表記（`5.00%`）の変換、および入力欄の初期化はこの画面の責務。
ヘッダへ `Teleport` するため、テストには `global: { stubs: { teleport: true } }` を付ける。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| HLV-01 | 取得が終わっていない | 画面をマウントする | 「読み込み中…」が表示され、現在値も設定変更フォームも表示されない | 実装済 |
| HLV-02 | 取得が 500 を返す | 画面をマウントする | エラーメッセージと「再試行」ボタンが表示され、設定変更フォームは表示されない | 実装済 |
| HLV-03 | 取得が本文なしを返す | 画面をマウントする | 「ハードリミットが設定されていません。」が表示される | 実装済 |
| HLV-04 | 既定モック | 画面をマウントする | モック表示である旨の注記と、`5.00%` / `10,000 株` / `USD 1,000,000` が表示される | 実装済 |
| HLV-05 | 既定モック | 画面をマウントする | 入力欄の初期値が 市場関与率 `5`、数量 `10000`、金額 `1000000` になる | 実装済 |
| HLV-06 | 既定モック | 市場関与率に `3` を入れて保存する | 「ハードリミットを保存しました。」が表示され、現在値の市場関与率が `3.00%` に変わる | 実装済 |
| HLV-07 | 既定モック | 市場関与率に `0` を入れて保存する | 保存できない理由が表示され、成功メッセージは表示されない。現在値は `5.00%` のまま | 実装済 |
| HLV-08 | 取得が 500 を返した後 | 「再試行」ボタンを押す（2 回目は成功する） | エラー表示が消え、現在値が表示される | 実装済 |
