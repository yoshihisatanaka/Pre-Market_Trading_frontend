# views/HoldingSearchView（預り検索）

- 略号: `HSV`
- 対象: `src/views/HoldingSearchView.vue`
- テスト: `src/views/HoldingSearchView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。`global: { stubs: { teleport: true } }` を付ける。
顧客検索と同じく、開いた時点で条件なしの一覧を出す（検索前の案内は置かない。2026-10-02 に変更）。
顧客名・買い / 売りのリンク先（名前付きルート `customer-summary` / `order-new`）を解決できるよう、テスト用ルータに同名のルートを置く。
実ブラウザでの URL 同期と画面遷移は E2E（[docs/e2e/holding-search.md](../e2e/holding-search.md) の `HSE`）が見る。
こちらは E2E では安定して観測できないもの（過渡状態・手で書き換えられた URL クエリ・送ったクエリ名・応答の差し替え）を担保する。

期待値はフィクスチャ（`src/mocks/fixtures/holdings.js` / `customers.js`）から導き、件数や行の中身をテストに直書きしない。
発注権限は `GET /auth/me` の既定モック（全権限あり）と、`server.use()` で差し替えた権限なしの応答で切り替える。
