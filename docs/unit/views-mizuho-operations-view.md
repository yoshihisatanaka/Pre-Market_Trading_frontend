# views/MizuhoOperationsView（みずほ注文締）

- 略号: `MZV`
- 対象: `src/views/MizuhoOperationsView.vue`
- テスト: `src/views/MizuhoOperationsView.spec.js`
- E2E 側のシナリオ: [docs/e2e/mizuho-operations.md](../e2e/mizuho-operations.md)

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、締めカードと約定一覧の
**4 状態をそれぞれ出し分ける**ことと、「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。
締めカードの操作（締め・締め解除・注文ファイル作成）は確認ダイアログで確定し、結果を画面上部の通知
（`mizuho-operations-notice`）に出す。
`global: { stubs: { teleport: true } }` を付ける。実ブラウザでの URL 同期とダウンロードは E2E が見る。
jsdom はダウンロードを実装していないので、`@/utils/download` を `vi.mock` して `downloadBlob` に何を渡したかを見る。
MSW の締め状態はハンドラの中で書き換わる。注文ファイルは締め済でないと 400 になるので、
注文ファイルのシナリオは画面の「みずほ注文締め」で締めてから進める。
