# views/OrderAmendView（外株注文訂正画面）

- 略号: `OAV`
- 対象: `src/views/OrderAmendView.vue`
- テスト: `src/views/OrderAmendView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**
（ローディング / 404 は not-found / その他のエラーは error + 再試行 / データあり）と、訂正できない状況の
locked 表示、入力検査、**変えた項目だけを送る**こと、受付後の完了表示を守る。
テスト用 router には `/orders/:orderId(\d+)/amend`（`order-amend`）と `/orders/inquiry`（`order-inquiry`）を定義する。
発注権限のガードは `router-permission-guard.md` が見るので、ここでは通さない。

対象注文はフィクスチャ（`src/mocks/fixtures/orderInquiry.js`）から引く:
#36 未発注・指値 / #34 注文中・成行 / #35 一部出来・成行（出来 1,200）/ #41 全部出来（訂正不可）。
サーバの文言は `src/mocks/handlers/orders.js` が返すもの。
