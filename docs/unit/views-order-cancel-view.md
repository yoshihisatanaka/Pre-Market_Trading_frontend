# views/OrderCancelView（注文取消画面）

- 略号: `OCV`
- 対象: `src/views/OrderCancelView.vue`
- テスト: `src/views/OrderCancelView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**
（ローディング / 404 は not-found / その他のエラーは error + 再試行 / データあり）と、取消できない状況の
locked 表示、取消の確定と完了表示を守る。この画面そのものが確認の段で、確認ダイアログは挟まない。
テスト用 router には `/orders/:orderId(\d+)/cancel`（`order-cancel`）と `/orders/inquiry`（`order-inquiry`）を定義する。
発注権限のガードは `router-permission-guard.md` が見るので、ここでは通さない。

対象注文はフィクスチャ（`src/mocks/fixtures/orderInquiry.js`）から引く:
#36 未発注 / #34 注文中 / #35 一部出来（出来 1,200）/ #41 全部出来（取消不可）。
サーバの文言は `src/mocks/handlers/orders.js` が返すもの。
