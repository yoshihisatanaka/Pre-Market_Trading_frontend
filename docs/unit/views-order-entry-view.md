# views/OrderEntryView（新規注文・外株注文入力画面）

- 略号: `NOV`
- 対象: `src/views/OrderEntryView.vue`
- テスト: `src/views/OrderEntryView.spec.js`

> `_template-view.md` から起こした。この画面は一覧ではなく「入力 → 確認 → 完了」の 3 段階なので、
> 雛形のページング・URL クエリの行は持たず、4 状態の後に段階ごとの導線を足している。

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通す。4 状態の起点は初期読み込み
（期間指定に使う受注不可日・海外休場日と、発注停止の状態）。照会は 400ms 待ってから走るので、ヒントの行は
実時間で待つ。それ以外の行は「打ってすぐ送信」でも照会が追い付く（送信前に照会を済ませる）ことに乗る。
既定の顧客は部店 `123` の `1230004`（警告なし）、警告ありは `1230001`（コンプラ A）。銘柄は AAPL、取引不可は BRK.B。
注文種別の選択肢はコードマスタ `VWAP区分` から来る。App.vue はコードマスタを読み終えてから
画面を描くので、テストもマウント前にコードマスタを読む。
