# views/OrderInquiryListView（注文照会画面）

- 略号: `OIV`
- 対象: `src/views/OrderInquiryListView.vue`
- テスト: `src/views/OrderInquiryListView.spec.js`（未実装）

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。`global: { stubs: { teleport: true } }` を付ける。
実ブラウザでの URL 同期と表の開閉は E2E が見る。こちらは E2E では安定して観測できないもの
（過渡状態・手で書き換えられた URL クエリ・応答の差し替え）を担保する。

訂正・取消はまだ処理が無いので、ここでは押しても落ちないことだけを見る。
