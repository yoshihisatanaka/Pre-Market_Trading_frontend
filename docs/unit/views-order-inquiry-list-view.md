# views/OrderInquiryListView（注文照会画面）

- 略号: `OIV`
- 対象: `src/views/OrderInquiryListView.vue`
- テスト: `src/views/OrderInquiryListView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**と
「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。`global: { stubs: { teleport: true } }` を付ける。
実ブラウザでの URL 同期と表の開閉は E2E が見る。こちらは E2E では安定して観測できないもの
（過渡状態・手で書き換えられた URL クエリ・応答の差し替え）を担保する。

発注権限は `GET /auth/me` の `order`。既定モックは管理責任者（権限あり）、権限なしは
`src/mocks/fixtures/currentOperator.js` の `noOperationOperator` を `server.use()` で返させる。
訂正・取消は別画面へ移るだけで、ルートは `order-amend` / `order-cancel`（テスト用 router に同名で定義する）。

出来状況の選択肢はコードマスタ `注文照会出来状況` から来て、値は処理状況コード。
App.vue はコードマスタを読み終えてから画面を描くので、テストもマウント前にコードマスタを読む。
