# views/PermissionListView（権限マスタ画面）

- 略号: `PMV`
- 対象: `src/views/PermissionListView.vue`
- テスト: `src/views/PermissionListView.spec.js`

実際の Pinia ストア + vue-router（`createMemoryHistory`）+ MSW(node) を通して、**4 状態の出し分け**、
編集可否（`/auth/me` のロール）による「操作」列と注記見出しの切り替え、編集ダイアログの保存・失敗・キャンセルを守る。
ヘッダへ `Teleport` するため `global: { stubs: { teleport: true } }` を付ける（`BaseModal` の `Teleport to="body"` も
同じ stub で wrapper 内に描かれる）。

ロールは 4 つ固定で検索もページングも無いので、雛形（`_template-view.md`）の URL クエリ系の行は持たない。
期待値（件数・ロール名・権限の許可 / 不可）はフィクスチャ `src/mocks/fixtures/permissions.js` と
`src/utils/permissionTypes.js` の `PERMISSION_ITEMS` / `permissionBadge` から導く。

| ID | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|
| PMV-01 | 応答を握ったまま | マウントする | ローディングが表示され、表と空表示とエラーは出ない | 実装済 |
| PMV-02 | `GET /masters/permissions` が 500 | マウントする | エラーの理由と「再試行」が表示され、表は出ない | 実装済 |
| PMV-03 | `roles: []` の応答 | マウントする | 「ロールが登録されていません。」が表示され、表は出ない | 実装済 |
| PMV-04 | 既定モック | マウントする | 件数が「〈ロール数〉 ロール」で、行がフィクスチャと同じ並び。各行にロール名・ロールコード・運用概要が出て、権限 4 列が許可 / 不可のバッジになる | 実装済 |
| PMV-05 | PMV-02 の状態 | 「再試行」を押す（応答は既定に戻す） | 一覧が表示される | 実装済 |
| PMV-06 | 既定モック（管理責任者） | マウントする | 列見出しの末尾に「操作」があり、全ロールに「編集」ボタンが出る。注記の見出しは「権限設定可能」 | 実装済 |
| PMV-07 | `/auth/me` が管理者（`viewerOperator`） | マウントする | 「操作」列も「編集」ボタンも出ない。注記の見出しは「閲覧のみ」。一覧は表示される | 実装済 |
| PMV-08 | `/auth/me` が 500 | マウントする | 一覧は表示され、「操作」列は出ず、注記の見出しは「閲覧のみ」 | 実装済 |
| PMV-09 | 既定モック | 行の「編集」を押す | 「〈ロール名〉の権限設定」のダイアログが開き、4 つのチェックがその行の権限どおりになる | 実装済 |
| PMV-10 | 既定モック | 不可の権限を 1 つチェックして「保存」 | ダイアログが閉じ、サーバの文言「〈ロール名〉の権限設定を更新しました。」が通知に出て、その行のバッジが許可に変わる | 実装済 |
| PMV-11 | 既定モック | 何も変えずに「保存」 | ダイアログが閉じ、通知に「変更はありません。」が出る | 実装済 |
| PMV-12 | PUT が 409（`detail` 付き） | チェックを変えて「保存」 | ダイアログは開いたままで、ダイアログ内のエラーにサーバの文言が出る。通知は出ず、行のバッジは変わらない | 実装済 |
| PMV-13 | 既定モック | チェックを変えて「キャンセル」し、同じ行の「編集」を開き直す | 行のバッジは変わらず、開き直したチェックは元の値に戻っている | 実装済 |
| PMV-14 | PMV-12 の状態 | 「キャンセル」してから「編集」を開き直す | 前回のエラーが出ていない | 実装済 |
| PMV-15 | PUT の応答を握る | 「保存」を押す | 保存ボタンが「保存中…」で押せず、キャンセルも押せない。応答後にダイアログが閉じる | 実装済 |
| PMV-16 | PMV-10 の後（通知が出ている） | ヘッダの「再読み込み」を押す | 通知が消え、一覧が表示される | 実装済 |
| PMV-17 | 既定モック | ローディング / データあり / エラー / 空 の各状態でマウントする | どの状態でも画面の注記（説明）が表示される | 実装済 |
