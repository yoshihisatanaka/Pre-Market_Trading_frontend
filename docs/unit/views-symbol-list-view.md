# views/SymbolListView（銘柄マスタ一覧画面）

- 略号: `STV`
- 対象: `src/views/SymbolListView.vue`
- テスト: `src/views/SymbolListView.spec.js`

実際の Pinia ストア + vue-router + MSW(node) を通して、
**4 状態の出し分け**と「ページ位置・検索条件は URL クエリが正」の単方向フローを守る。

実ブラウザでの URL 同期は銘柄マスタの E2E シナリオ（`docs/e2e/` 配下・別途）が見る。
こちらは E2E では安定して観測できないもの（過渡状態・手で書き換えられた URL クエリ・
応答の差し替え）を担保する。分担は次のとおり。

| 論点 | E2E | 単体 | 理由 |
|---|---|---|---|
| ページ送り・検索の URL 同期 | E2E 側で見る | STV-12 / 13 / 14 | 実ブラウザの履歴まで見るのは E2E、条件の受け渡しは単体 |
| 未知の `regulation` | — | STV-15 | 画面の導線からは起こらない（手で URL を書いたときだけ） |
| 区分名が欠けた応答 | — | STV-07 | 応答の差し替えが要る。実 API は常に付けて返す |
| 表示件数の倍数でない `offset` | — | STV-11 | 同上。画面の導線からは起こらない |
| 相場が未取得（`null`）の行 | — | STV-05 | フィクスチャ依存の行を狙い撃つ |

検証するのは**表示名**であって、取引可否セルの色ではない。`規制情報` のコード値は
仮置き（[utils-symbol-types.md](utils-symbol-types.md)）で、差し替わると色の条件も変わるため。

この画面は**一覧・新規追加・編集**を持つ（削除はまだ無い。STV-17）。
追加・編集についての分担は次のとおり。手本は
[views-corporate-action-list-view.md](views-corporate-action-list-view.md)（CAV-17〜33）。

| 論点 | E2E | 単体 | 理由 |
|---|---|---|---|
| 追加できること・成功の見えかた | SM-15 / 20 | STV-20 | 実ブラウザで通ることは E2E、条件を保った読み直しは単体 |
| 必須 3 項目の未入力 | SM-14 | STV-19 | 文言と出る位置は単体のほうが細かく見られる |
| 事前検証の不合格と通信障害の出し分け | SM-16 / 17 | STV-21 / 22 | 応答の差し替えが要る |
| 登録中はキャンセルもできない | — | STV-23 | 過渡状態は E2E では安定して観測できない |
| 編集できること・現在値が入ること | SM-21 / 22 | STV-26 / 27 | 実ブラウザで通ることは E2E、一覧の該当行の中身は単体 |
| 更新中はキャンセルもできない | — | STV-31 | 応答を握る必要があり実ブラウザでは安定しない |
| 追加と編集でエラーの枠が混ざらないこと | — | STV-32 | 片方のモーダルを開き直す操作が要り、E2E では回りくどい |
| 相場が `null` の行を編集で開く | — | STV-33 | 応答の差し替えが要る |
| 絞り込み中の変更でのページ戻し | — | STV-34 | 空状態が一瞬挟まる過渡状態 |

**編集では銘柄コードを変更できない。** 主キーが `id` になって銘柄コードは一意な業務コードに
格下げされたが、実 API の詳細照会・更新履歴が `/masters/symbols/{symbol}` としてこの値で
1 件を指すため、入力欄を読み取り専用にする（STV-26）。項目の増減ではなく 1 属性の切り替えに
留めてあるので、追加と編集で 10 項目が一致するという部品化の狙いは保たれる。

STV-26 が見るのは `readonly` 属性の有無であって、**見た目ではない**。jsdom は `<style scoped>` を
適用しないので「面が一段沈む」ことは単体テストでは検証できない（Playwright MCP で目視する）。

画面が自分で弾くのは**必須 3 項目（銘柄コード・ティッカーコード・銘柄名（日本語））が
空でないこと**だけ。銘柄コードの重複・文字数超過・コードの実在はサーバの事前検証が見る
（重複の出しかたは STV-21）。区分 3 つは未選択を作らず実 API の既定（`'0'`）から始めるので、
選択の必須検証は無い（STV-25）。

**`市場名` / `前日出来高` / `Pre区分` はフォームに無い。** 画面から作れない項目なので送らない
（`src/api/symbols.js` の JSDoc に理由がある）。入力欄の並びと `data-testid` は
`src/components/symbol/SymbolFormFields.vue` が持ち、追加と編集でずれないように部品化してある
（`src/components/masters/` と同じ扱いで、その部品単独のシナリオ文書は持たない）。
